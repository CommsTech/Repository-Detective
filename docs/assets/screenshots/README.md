# Documentation screenshots

Capture with `./scripts/capture-doc-screenshots.sh` against a running operator UI.

Required images (no secrets, no API keys in URLs):

| File | Page |
|------|------|
| dashboard.png | `/ui/` dashboard |
| repos-list.png | `/ui/repos` |
| repo-detail.png | `/ui/repos/1` |
| scan-now-modal.png | Scan Now modal |
| configure.png | `/ui/configure` |
| configure-secret-scan.png | Configure secret scanning section |
| preinstall.png | `/ui/preinstall` |
| learning.png | `/ui/learning` |
| reconciliation.png | Repo reconciliation panel |
| executive-report.png | Executive report |
| scanner-status.png | System health / scanner flags |

Use dark or light mode consistently. Redact private repo names if docs are public-facing.
