# Sponsorship

Repository Detective is maintained by a solo developer. Sponsorship is
voluntary and funds maintenance, testing, documentation and the review work
that keeps findings trustworthy.

**What sponsorship does not buy:** guaranteed response times, priority fixes,
private support, security outcomes, or any service-level agreement. The
project is provided under AGPL-3.0-or-later without warranty.

## Proposed tiers

| Tier | Monthly | Benefit |
|---|---|---|
| Supporter | $5 | Sustains maintenance; named thanks in the welcome message. |
| Builder | $15 | Above, plus optional public acknowledgment in the README. |
| Sustainer | $50 | Above, plus optional listing in a supporters section of the README. |

Public acknowledgment is opt-in. Anonymous sponsors are never listed.

## Status

Not yet enrolled. GitHub Sponsors enrollment is completed by the account owner
in the GitHub UI; it cannot be enabled through the API. Until the sponsor
profile is approved and publicly reachable, no `.github/FUNDING.yml` is
committed, because a funding file that points at a missing profile is a broken
call to action.

## Owner checklist

1. Enable two-factor authentication and confirm the account is in a
   [supported region](https://docs.github.com/en/sponsors/getting-started-with-github-sponsors/about-github-sponsors).
2. At <https://github.com/sponsors>, choose **Get sponsored**, select the
   personal account, enter contact details, choose a payout method, submit.
3. After the initial review, open **Your sponsors → Dashboard → Profile
   details** and add the profile text below.
4. Under **Sponsor tiers**, publish the three tiers above. Complete payout and
   tax setup.
5. Request approval. Review timing is not guaranteed.
6. Only after the profile is live: add `.github/FUNDING.yml` containing the
   personal username, then verify the rendered sponsor button.
