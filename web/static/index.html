1. Connect

Configure forge access and prove the token works. Secrets stay in the browser until you export env values.

Operator login (recommended for new installs)

After you start with the exported .env, create the first operator account at /ui/bootstrap (available only while no local users exist). Daily UI access is /ui/login — do not paste the automation API token into the login form.
